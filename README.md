# 陪玩搭子 · cortico-world-gamebuddy

桌宠陪你打游戏：知道你在打哪一局、隔一阵子吐槽一句，你要建议时给能立刻执行的打法。内置**三国杀**档位。

## 它做三件事

1. **知道你上号了**：每 8 秒扫一次窗口标题（PowerShell），匹配到游戏就开一局「陪玩会话」，消失就收工。
2. **时不时搭话**：默认每 150 秒最多一次（`commentEverySec`），把「已陪多久 + 最近读到的局势」作为事件投进对话，让**你自己的那只宠物**用它的嘴说出来（语气、人格、记忆都不变）。
3. **给决策**：`gamebuddy_advise` 是纯规则引擎——身份目标、血线、牌序、留牌、AOE 与无懈的时机。不联网、不额外调模型。

读屏是可选的第二层：截图 + Windows OCR → 三国杀字段解析（身份 / 体力 / 手牌数 / 阶段 / 认出的牌 / 判定区）。

## 数据边界（读什么、发给谁、存在哪、怎么关）

这一节写得直白些，因为它标了 `sensitive-data`（读隐私）和 `injection-risk`（第三方文字进上下文）两个红色标签。

### 会读到什么

| 数据 | 什么时候 | 怎么读 |
|---|---|---|
| 窗口标题、类名、进程名、窗口尺寸 | 每 8 秒一次（`pollSec`） | PowerShell 枚举顶层窗口，只取这几项，不读画面 |
| 游戏截图 | 三种时机：你让它「读一眼」、后台预读（**仅游戏窗口在前台**，每 3 秒，`refreshSec`）、到搭话节奏点 | 截当前游戏窗口存本机，并**另裁一张手牌特写** |
| 直播弹幕 | 只有当你在 Coopanion 里装了 bilibili 直播世界时 | 读的是**本机事件库**（`host.store`），它不会自己去连 B 站 |

**不会读**：键盘输入、剪贴板、其他窗口的内容、账号密码、聊天记录。

### 会发给谁

1. **你配置的模型端点**——截图作为工具回执的图片附件，随那一次模型调用一起发过去。这是 `sensitive-data` 警告的来源：它确实把你的屏幕内容发给了模型服务商。
2. **三国杀 wiki**（`wiki.biligame.com` 的 msgs / sgs / sgsol）——只在你问到库里没有的武将时查一次，只发武将名字，不发截图。
3. **没有第三方服务器**：这个插件本身不做统计上报、不链图床、不把数据发给作者。

### 存在哪

全部在本机 `dataDir`（Coopanion 里是 `data/home/companion/data`）：

```
generals-user.json    你教/联网补的武将
slang-user.json       你加的黑话
harvest.json          采集到的候选词与最近弹幕
frames/look-*.jpg     读屏截图，只留最新 20 张
frames/live.jpg       后台预读图，固定覆盖
frames/hand-focus.jpg 手牌特写，固定覆盖
```

数据库编辑页（`http://127.0.0.1:17790`）只监听回环地址，别把这个端口做端口转发。

### 怎么关

| 想关掉 | 改哪个 |
|---|---|
| 不再截图 | `worlds.gamebuddy.ocr = false` |
| 截图但不发给模型 | `sendImage = false` |
| 不联网查武将 | `autoLearn = false` |
| 不读弹幕 | `harvest = false` |
| 不记新武将 / 新黑话 | `collectGenerals = false` / `collectSlang = false`（面板上也有开关） |
| 整个陪玩停摆 | `armed = false`（面板上那个总开关） |
| 关掉数据库编辑页 | `editor = false` |

关掉采集只是「不再记新的」，已经入库的照常能查；删库要你自己删文件，插件不替你删。

### 它不会做的事

- 不改游戏文件、不注入进程、不读内存、不模拟点击——那是另一个独立插件 `cortico-world-autoplay` 的事，而且要你自己打开。
- 不把任何数据发给作者或第三方服务（只有上面「会发给谁」里的两处）。
- 不在你看不见的时候偷偷截图：后台预读要求游戏窗口**在前台**且陪玩开关是开的。

## 本地武将库（问技能快在哪）

技能不再靠模型回忆，而是查本地文件：

- `data/generals.json` —— 随包分发的内置库（32 名，覆盖标准包 + 你常玩的界将）；
- `<dataDir>/generals-user.json` —— 用户库，由 `gamebuddy_teach` 写入，同名**覆盖**内置条目。

查一次约 **0.2 微秒**（实测 1 万次平均），比模型自己推理快三个数量级。而且读屏时会把画面里认出武将的摘要**直接塞进环境提示词**（`{{gamebuddy.generals}}`），所以问场上武将的技能通常连工具都不用调。

三个入口：

| 场景 | 走哪 |
|---|---|
| 问场上武将 | 环境提示词里已经有摘要，直接答 |
| 问别的武将 | `gamebuddy_general("简雍")`，本地命中 |
| 库里没有 | 让主人发原文 → `gamebuddy_teach` 存一次，下次就命中 |

补武将最省事的方式：直接改 `data/generals.json`（改完重启 Coopanion），或者对宠物说「记住：XX 的技能是……」，它会调 `gamebuddy_teach` 写进用户库。

### 库外武将自动补

问到库里没有的武将时，`gamebuddy_general` **会自动联网补一次**，不用你教：

```
第 1 次（~400ms）→ [learned] 已从三国杀移动版 wiki 抓好并存入，下次起本地命中
第 2 次（0ms）    → [general] 直接命中
```

**多数据源，按顺序 fallback**（`worlds.gamebuddy.wikiSource` 控制，默认 `auto`）：

| 顺序 | 源 | 地址 | 说明 |
|---|---|---|---|
| 1 | 三国杀**移动版** | `wiki.biligame.com/msgs` | 手机上打的版本，技能描述以它为准 |
| 2 | 三国杀（综合） | `wiki.biligame.com/sgs` | 覆盖面最广，移动版缺词条时兜底 |
| 3 | 三国杀 OL | `wiki.biligame.com/sgsol` | 再兜一层 |

- 每个源都是同一套 MediaWiki API：搜索标题 → 取 wikitext 的势力/体力 + HTML 的技能块，解析器共用；
- 前一个源连不上/没这个词条/没解析出技能，才换下一个；全部失败才返回 `[miss]`；
- 排除干扰页：皮肤页（`*`）、`武将`/`皮肤`/`新手` 列表页、模板/分类命名空间；
- 国战专用技能（副将技/主将技/阵法技/阴阳鱼）在有身份局技能时会被剔掉；
- 只抓一次，写进 `generals-user.json`，条目 `source` 里保留命中站的链接；
- 抓失败会**记 10 分钟负缓存**，不会每次提问都卡在超时上；
- 不想要联网就把 `worlds.gamebuddy.autoLearn` 设为 `false`。

## 黑话库（听得懂人话）

三国杀玩家不按书上的名字叫牌和将：荀彧是「狗货」，关羽是「二爷」，乐不思蜀是「乐」，过河拆桥是「过拆」，反贼明着打主叫「跳反」。这些不进武将库（它们是**说法**，不是**技能**），单独一个库：

- `data/slang.json` —— 内置 68 条：武将别称、常见梗、术语、牌/装备简称；
- `<dataDir>/slang-user.json` —— 用户库，编辑器页面写这里，同名词条覆盖内置。

用法：

| 入口 | 行为 |
|---|---|
| `gamebuddy_slang("狗货")` | 返回释义 + 它指涉的武将（荀彧）的技能摘要，一次往返答完 |
| `gamebuddy_general("二爷")` | 武将库没命中时会自动转黑话库，认出来就返回关羽的技能 |
| 读屏 | 画面里出现的黑话会进环境提示词（`{{gamebuddy.slang}}`），宠物说话时用对词 |

单字别名（「乐」「电」）只支持精确查询，不参与画面自动识别，避免满屏"乐"误报。

## 数据库编辑页面（直接改，不用碰 JSON）

Coopanion 启动时会顺手在 `127.0.0.1` 起一个小网页：

```
http://127.0.0.1:17790/
```

- 左上三个页签：**武将库** / **黑话库** / **采集**，数字是当前条数；
- 左栏搜索（名字、技能原文、别称都能搜），右边表单直接改，**保存立刻生效**——写的是用户库，宠物下一次查询就是新内容；
- 武将表：名字 / 势力 / 体力上限 / 技能（每行一条，`技能名｜描述`）/ 打法 / 克制；
- 黑话表：词条 / 类型（别称·梗·术语·牌）/ 别名 / 关联武将 / 释义 / 备注；
- 条目可以直接用锚点分享：`#generals/姜维`、`#slang/乐`；
- 内置条目删不掉（会提示），但可以**改成覆盖版**保存，效果等同改原文。

只监听回环地址、没有鉴权——同机进程能访问，外网进不来。端口被占会自动往后挪，实际地址看 Coopanion 日志里的 `数据库编辑器：http://...`，或者宠物面板的「库」徽标。

面板里的入口：`invoke('editor')` 返回 `{url, generals, slang}`，`invoke('openEditor')` 用默认浏览器直接打开。



## 安装

装到 Coopanion 里（发布到 npm 之后从扩展市场搜「陪玩搭子-三国杀」即可）：

```powershell
cd <Coopanion 数据目录>/extensions
pnpm add cortico-world-gamebuddy --store-dir <Coopanion 数据目录>/pnpm/store
```

本地开发想直接挂上去，用软链：

```powershell
cd <Coopanion 数据目录>/extensions
pnpm add "link:<这个仓库的绝对路径>" --store-dir <Coopanion 数据目录>/pnpm/store
```

`link:` 装法改完代码**重启 Coopanion** 就生效，不用重装。
配置写在 `data/home/companion/config.json` 的 `worlds.gamebuddy`。删掉那一节并 `pnpm remove cortico-world-gamebuddy` 即可卸载。

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 整个包的开关，框架读它决定挂不挂载 |
| `armed` | `true` | **陪玩总开关**：关掉后不搭话、不读屏、工具直接拒绝；面板开关会写回这里，重启后保持 |
| `game` | `sanguosha` | `sanguosha` 启用解析与规则；`generic` 只陪聊 |

| `refreshSec` | `3` | 打游戏时后台预读画面的间隔（秒），`0` 关掉；开着时问打法基本不用等读屏 |
| `commentEverySec` | `60` | 两次主动搭话的最小间隔（秒） |

| `autoLearn` | `true` | 库外武将自动联网补一次 |
| `wikiSource` | `auto` | 优先数据源：`auto` / `msgs` / `sgs` / `sgsol` |
| `editor` | `true` | 起数据库编辑页面（127.0.0.1） |
| `editorPort` | `17790` | 编辑页面端口，被占自动 +1 重试 |
| `harvest` | `true` | 直播采集：记对局武将 + 攒弹幕黑话候选 |
| `harvestSec` | `15` | 多久读一次直播事件（秒） |
| `collectGenerals` | `true` | 武将库采集开关（面板上也能点） |
| `collectSlang` | `true` | 黑话库采集开关（面板上也能点） |

## 直播采集（边播边记，确认才入库）

直播陪玩时，插件会自己在后台读两条信息源：

| 来源 | 怎么来的 | 记什么 |
|---|---|---|
| 游戏画面 | 每次 `gamebuddy_look` 认出武将时 | 武将名、见过几次、是否已入库；没入库的会自动联网补一次 |
| 直播弹幕 | 读直播世界归档进事件库的 `bilibili.danmaku`（按游标增量读，重启不重扫） | 已知黑话的出现次数；**反复出现两次以上**的未知词进候选 |

采集结果写在 `dataDir/harvest.json`，**不会自动进库**——要主人在编辑器的「采集」页点「入库」，或者由宠物问一句「XX 是什么梗」。

- 编辑器「采集」页：三个列表（对局武将 / 黑话候选 / 最近弹幕），按钮是「联网补库」「入库」「忽略」；
- 接口：`GET /api/harvest`、`POST /api/harvest/accept|ignore|learn`；
- 词条切分先挖掉已认得的黑话与武将名（否则「狗货又来」会被切成「货又」「又来」），再只留被提过两次以上的片段；
- 同一个概念的其它切法（`翻盘点` / `翻盘` / `盘点`）在入库时一并收掉，清单不会重复；
- 两小时内只出现一次的碎片会在保存时自动清掉，文件不会越滚越大；
- 直播弹幕里的同一个词反复出现时，会推一个 `gamebuddy.harvest` 事件，让宠物去问主人——认得就解释，不认得就直接问。

没有开直播也不影响：读不到弹幕就是空转，武将照样从画面记。

### 两个库各有一个开关

面板「陪玩中」那行下面还有两个小开关，各管一半：

| 开关 | 关掉之后 |
|---|---|
| **武将库采集** | 读屏认出的武将自己不再记；`learnMissingGeneral` 也不补库；`gamebuddy_harvest` 里武将列表停在原样 |
| **黑话库采集** | 弹幕不再切词攒候选，已知黑话也不再记次数；事件照读、游标照推进，不会积压 |

用起来就是「想要新料就打开，专心打就关掉」。关掉不删数据、不影响已入库的词条，随时开回来继续攒。两个开关都写在配置里（`collectGenerals` / `collectSlang`），面板上点一下立刻持久化，重启保持；设置页里也有同样的两项。

## 开关

面板最上面那一行就是总开关，一眼能看出状态：

- **陪玩中**（绿色）→ 点一下变**已关闭**：立刻停止扫描、不再主动搭话，`gamebuddy_look` / `gamebuddy_advise` 都回 `[off]`，下面三个按钮同时变灰；
- **已关闭** → 点一下恢复；状态写进 `worlds.gamebuddy.armed`，重启应用后还记得。

关着的时候连窗口都不扫（不占 CPU），宠物那边只会看到「陪玩已关闭」，不会自己找活干。

## 工具（宠物自己会调）

| 工具 | 作用 |
|---|---|
| `gamebuddy_status` | 游戏在不在跑、是否前台、陪了多久、搭话几次、有没有读到牌面 |
| `gamebuddy_look` | 立刻截图 + OCR，返回 `[board]` 局势与 `[text]` 原文前 24 行；识别不出来会明说 |
| `gamebuddy_advise` | 规则版打法。可选 `situation`（口述局势）与 `question`（你在纠结什么） |
| `gamebuddy_general` | 查武将技能：本地库 → 黑话别名 → 自动联网补库 |
| `gamebuddy_slang` | 查黑话/别称/简称，命中时顺带返回对应武将技能 |
| `gamebuddy_teach` | 把技能原文写进本地武将库（同名词条覆盖） |
| `gamebuddy_slang_add` | 把一条黑话写进黑话库：`term` + `meaning`，可带 `aliases`/`usage`/`generals`/`kind`；同名词条覆盖，写完立即生效 |
| `gamebuddy_harvest` | 看直播采集清单：遇到的武将（哪些没入库）、黑话候选 |

## 事件

| 事件 | 触发 | 正文带什么 |
|---|---|---|
| `gamebuddy.start` | 游戏窗口出现 | 进程、窗口标题 |
| `gamebuddy.tick` | 到节奏点且在前台 | 已陪分钟数、第几次、最近局势 |
| `gamebuddy.end` | 窗口消失 | 总时长、搭话次数、这局遇到的武将 |
| `gamebuddy.harvest` | 弹幕里同一个词反复出现 | 词、出现次数、一句例句 |

## 工作方式（为什么这么切）

- **不自己调模型**：搭子只产出「事实 + 该说话了的信号」，话由宿主的宠物说。这样语气/人格/记忆统一，也避免重复计费。
- **不假装看得见**：`gamebuddy_look` 会把 OCR 置信度一并给出，置信度低时提示词要求它先问一句，而不是编牌。
- **规则与语言分离**：牌序、留牌、身份目标是代码里的死规则，模型只负责把它讲成人话——模型胡说也不会把「先拆顺再杀」说反。

## 已知限制

- **只支持 Windows**：观测层用 PowerShell 5.1 + `System.Drawing` + `Windows.Media.Ocr`。macOS/Linux 需要另写观测层。
- **OCR 依赖你的客户端排版**：`src/parse.ts` 认的是稳定文字（牌名、`3/4` 这种血量、`手牌 4`、阶段词）。不同客户端（OL / 十周年 / 无名杀 / Steam）排版差异很大，认不出就只会留空。
- **OCR 认不全手写牌名**：卡面是艺术字，Windows OCR 对「闪 / 杀 / 骅骝 / 无懈可击」这类字形经常读不出。所以读屏时会额外裁一张**手牌特写**（放大 2 倍）作为第二张图给模型看——牌名以图为准，OCR 只当辅助。真遇到某个客户端连图都看不清，跑 `node diagnose.mjs` 看锐度定位问题。
- **窗口标题匹配**：浏览器里玩网页版三国杀时，标题通常只有"三国杀"或标签名，可能要放宽 `windowPattern`。

## 自动打牌（已拆成独立插件）

自动打牌不再住在这个包里：它在 `autoplay/`（包名 `cortico-world-autoplay`，世界 id `autoplay`），有自己的总开关、adb 桥、规则引擎、批量执行和面板。

这边保留的是**陪玩**：看画面、算打法、武将库、黑话库、直播采集、数据库编辑页。两个插件可以各开各的——陪玩照着打，自动打牌自己动手，或者只开一个。
